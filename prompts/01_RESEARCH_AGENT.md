# Research task template

Topic: [TITLE]
Video question: [CENTRAL QUESTION]
Location / era / building type: [SCOPE]

Research the question using reputable architectural/historical sources. Output `research/sources.json` and `research/research_notes.md`:
- Each factual claim gets a unique CLM ID and precise source IDs/URLs.
- Distinguish established facts, debated interpretations, and visualization assumptions.
- Explain whether designs coexisted; never imply a global linear evolution from a few examples.
- Identify 3D-visible architectural differences and what makes each important.
- License-check proposed archival images/models; don't download unapproved assets.
- Include uncertainties. If evidence is inadequate, mark provisional and do not invent facts.
