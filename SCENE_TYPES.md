# Scene types for future episodes

- `DESIGN_DECISION`: one design A → constraints → design B; explain trade-offs, don't oversell one winner.
- `HISTORICAL_EVOLUTION`: dated architecture examples with source evidence; view transitions and differences; no fabricated global development sequence.
- `REGIONAL_COMPARISON`: matched building purpose/time, controlled scale/camera; include qualifications.
- `TECHNICAL_EXPLAINER`: diagram/cutaway of physical mechanism; state simulation limits.
- `ARCHIVAL_CONTEXT`: historical photos/maps/blueprints, credits and licenses, Ken Burns/pan/zoom.

Remember: **visuals teach a claim**, they are not decorative animation loops. Every `shot_id` must have a learning purpose.
