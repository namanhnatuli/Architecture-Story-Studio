# Shared Asset Library

Purpose: reuse architecture parts without re-creating every video. Every external 3D asset must be accompanied by `asset_id`, creator, URL, license, credit text, scale/unit and usage notes.

Suggested categories: `roofs`, `walls`, `bridges`, `houses`, `materials`. All folders are deliberately empty: sample roof models are generated entirely in Python.

Do NOT paste random downloaded model packs here without checking commercial reuse and derivative-work license conditions.
