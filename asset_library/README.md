# Shared Asset Library

Reusable architecture for any project. Since M4 most assets here are **procedural specifications** (JSON) that
`engine/arch` turns into semantic Blender models; nothing is downloaded.

```text
asset_library/
├── architecture/
│   ├── bridges/        bridge_*.json specs (+ previews/<asset_id>/<preset>/*.jpg; PNGs are local only)
│   ├── sites/          shared context (river crossing)
│   └── structural_components/README.md   reusable primitives (engine/arch/library.py)
├── materials/stylized_materials.json     shared procedural PBR materials (no textures)
├── procedural_generators/README.md       where the generators live (engine/arch/families/)
├── catalog/            catalog.json, CATALOG.md, offline_checks.json, qa/<asset>_<preset>.json
└── houses/ roofs/ walls/   (pre-M4 categories; house/roof models are generated by engine/geometry.py)
```

Use an asset in any project's `storyboard/states.json`:
```json
{"base": {"builder": "architecture_asset", "asset": "asset_library/architecture/sites/site_river_crossing_24.json"},
 "shared_components": ["banks", "water"],
 "variants": [{"id": "stone_arch", "builder": "architecture_asset",
               "asset": "asset_library/architecture/bridges/bridge_stone_arch_03.json"}]}
```

Accuracy levels: `ILLUSTRATIVE` (all current assets), `REFERENCE_BASED` (needs provenance.references),
`HISTORICALLY_VERIFIED` (needs claim_ids backed by a research ledger). Every external 3D model or texture would
need asset_id, creator, URL, licence, credit text, scale/unit and usage notes in `provenance.external_assets`.
Do NOT paste downloaded model packs here without checking commercial reuse and derivative-work licence conditions.

Docs: `docs/m4/M4_ARCHITECTURE_MODELING.md`.
